# openmodbus-spec Releases

## v0.1.0

**Date:** 2026-10-31

First tagged snapshot, so that the schema and the test vectors have a version to pin. It is still a draft: the sections marked **[proposed]** need sign-off and the decisions in `docs/PROPOSAL.md` are open, so a later version may change anything here.

### Added

- Draft specification, `spec/openmodbus-0.1-draft.md`.
- JSON Schema under `schema/0.1/`.
- Three example documents for fictional devices, under `examples/`.
- Language-neutral decode vectors, `conformance/decode-vectors.yaml`.
